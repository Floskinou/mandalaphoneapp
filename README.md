# Mandala Yoga & Pilates — Application mobile

Application iPhone & Android de Pilates et Yoga, avec suivi de cycle, humeur, hydratation, défis et abonnement.

## Contenus

Les séances sont gérées via Supabase (tables `workouts`, `programs`, `challenges`) et un panneau d’administration web (`admin/index.html`).

## Stack

- React Native + Expo SDK 57
- Supabase (contenus + auth admin)
- EAS Build (APK/IPA)
